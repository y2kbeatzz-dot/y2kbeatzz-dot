DATA & PRIVACY · VERSION 1.4.0

Your music.
Your browser.

Updated October 14, 2026. This page describes the published Crystal Lyrics 1.4.0 extension and this download website. The extension does not include analytics, advertising, an account system or a subscription.

What stays on your device

Preferences, colors, lyric choices, imported lyrics, custom fonts, timing corrections and bounded lyric/timing caches are stored in your browser profile. The optional audio model is cached by the browser separately. These settings do not use an extension account or cloud sync.

When the extension contacts other services

ServicePurpose and information sent
LRCLIBLooks up lyrics using song title, artist, duration or your search query. Requests omit YouTube account cookies.
Apple iTunes Search API and artwork serversOnly when cover colors are enabled: searches by song title and artist, then downloads matching artwork for local palette extraction. The palette and matched metadata are cached; the cover image is discarded after extraction.
Hugging Face and its download infrastructureDownloads model files when you start optional local audio timing. Your captured audio, imported lyrics and custom font files are not uploaded to Hugging Face.

External services receive ordinary connection metadata, including your IP address. Their own practices apply to these requests. The source code contains the exact hosts and request behavior.

Optional audio timing

Clicking Learn this song starts capture of the selected YouTube tab’s audio. The song restarts so timing can be learned while it plays. The extension does not capture your microphone or camera.

Captured audio is held temporarily, processed on your computer and discarded after analysis. Only the resulting word timings are saved. You can cancel the capture. First use downloads an approximately 80 MB model, and processing speed depends on your computer and the song.

Video colors

Video color mode samples a small frame locally in memory. Frames are not saved or uploaded. This mode does not start audio capture, screen recording or camera access. Protected or cross-origin video content can prevent sampling.

Why the permissions exist

  • Storage: remembers preferences and lyric/timing data.
  • Active tab: lets the popup control the current supported song tab.
  • Tab capture and offscreen document: support the audio timing tool after you start it.
  • YouTube and YouTube Music page access: reads the current song and video clock, and adds the lyric interface.
  • Named music and model hosts: support the lookups and downloads described above.

Removing stored data

Removing the extension removes its extension storage from that browser profile. A separately cached model may remain until the relevant browser cache is cleared. The extension has no remote account to delete. Back up any imported lyric files you want to keep before removing it.

This website

The website’s code has no analytics scripts, advertising trackers, cookies or third-party font requests. The interactive preview uses original demo text and makes no music-service requests. Its settings are kept only for the current page session. The copy button writes the selected extension-page address to your clipboard when clicked.

The hosting provider processes network requests to serve the site and downloads. Downloading the extension from this website does not install it automatically. Links to GitHub and other external sites are subject to those services’ own practices.

Questions or changes

Report a concern through the Crystal Lyrics issue link. GitHub issues are public; please do not post private account details or song files there. This page will be updated when the published extension’s behavior changes.
