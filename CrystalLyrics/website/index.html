What does Crystal Lyrics actually do?+

It adds a customizable lyric panel and an optional video lyric overlay to desktop YouTube and YouTube Music. Lyrics follow playback when timed lyrics are available. You can change fonts, colors, transparency, layout and effects.

Is it really free?+

Yes. This release has no payment, subscription, account or API key. Download the complete ZIP and follow the manual installation steps above. An internet connection is needed for online lyric and cover lookups.

Are the words perfectly synced for every song?+

No. Supplied word timestamps are used when available. Otherwise AUTO WORDS estimates timing within each timestamped line. You can import a matching timed lyric file, adjust the delay, or try optional local audio timing. Singing recognition and estimates can both be imperfect.

Does it record my microphone?+

No. The optional “Learn this song” tool captures only the active song tab’s audio after you start it. Audio is processed locally and discarded after analysis. First use downloads an approximately 80 MB model. Normal lyric display does not need audio capture.

What leaves my browser?+

Song metadata is sent to LRCLIB for lyric lookup. If cover colors are enabled, song metadata is also sent to Apple’s iTunes Search API. Optional local timing downloads a model from Hugging Face. These services receive normal network information, such as your IP address. Audio, custom fonts and imported lyrics are not uploaded. Read the full data details.

Can I use it on Firefox or my phone?+

This release targets desktop Chrome and Edge 116 or newer. Firefox, Safari, mobile browsers, YouTube Shorts, live streams and embedded players are not supported in this release.

How do I update without losing my settings?+

Download the new version and replace the files in the same CrystalLyrics folder. On the browser’s extensions page, click Reload for CrystalLyrics, then refresh YouTube. Keeping the same folder helps preserve the extension identity and your saved settings.
