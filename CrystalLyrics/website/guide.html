INSTALL & USE · VERSION 1.4.0

A few steps.
Then your music.

Crystal Lyrics runs on standard desktop YouTube and YouTube Music watch pages in Chrome or Edge 116 and later. This release is a complete unpacked extension, with everything needed for installation included in the ZIP.

Download v1.4.0 · 23.3 MB ↓

Install on Chrome or Edge

  1. Download the ZIP. On Windows, right-click it and select Extract All. Choose a folder you will keep, such as Documents. Keep the extracted folder after installation.
  2. Open chrome://extensions in Chrome, or edge://extensions in Edge. Paste the address directly into the browser’s address bar.
  3. Enable Developer mode, then choose Load unpacked.
  4. Select the inner CrystalLyrics folder containing manifest.json. Do not select the ZIP or its outer downloads folder.
  5. Refresh any open YouTube or YouTube Music tabs. Play a song. Pin CrystalLyrics from the browser’s Extensions menu and click its icon if you need to show the lyric panel.

You do not need Node.js, Python, an installer, an API key or a server. The optional local audio timing feature downloads its model separately on first use. This download is not a Chrome Web Store listing.

Find the right lyrics

Automatic lookup uses the song’s title, artist and duration. Fan uploads, remixes and edited videos can have misleading metadata. Choose Find song and select the correct recording when needed.

You can also import LRC, enhanced LRC, SRT, VTT and timed .lyricsfile.yaml files through Load lyrics. Untimed text stays readable, but cannot follow playback automatically.

Understand the timing label

LabelMeaning
WORD SYNCThe lyric source supplies word timestamps.
AUTO WORDSWord timing is estimated inside each timestamped line.
MIXED WORDSSupplied word timestamps plus estimated words.
AUDIO WORDSWord positions learned from local tab audio.
AUDIO + AUTOAudio timing with estimates for missed words.
LINE SYNCLine timestamps, with the automatic word effect off.
UNTIMEDPlain lyrics without playback highlighting.

Neither estimated word timing nor audio recognition guarantees exact sync. Use lyric delay for an early or late start. A positive delay shows lyrics later; a negative delay shows them earlier. A video with cuts or a different song version may need a matching lyric file.

Make it look like you

  • Open Style in the lyric panel, or use the extension popup.
  • Pick a font, word colors, glow strength and each box’s font size.
  • Set the panel or video background to 0% for full transparency.
  • Drag the panel’s title bar. Resize it from its corner handles.
  • Enable Edit video box to move or resize the video overlay, then select Done.
  • Choose Use cover art colors or Use video colors. Selecting one switches the other off. Turn both off to return to your saved manual colors.
  • Turn individual effects on or off. Reduced motion starts enabled.

Optional: learn timing from tab audio

  1. Load the correct lyrics and open the extension popup.
  2. Expand Local audio timing, then select Learn this song.
  3. The song restarts. Let it play while the extension captures the tab’s audio locally.
  4. Wait for analysis to finish, then replay the song to use the saved timing.

You can choose Finish & analyze for the captured part, or Cancel. First use downloads an approximately 80 MB model. Singing, background instruments and remixes can make recognition inaccurate. Your microphone is not used. See the data and privacy details.

Update an existing installation

  1. Download the latest version and extract it.
  2. Copy the new files into the same CrystalLyrics folder you originally loaded, replacing the old files.
  3. Open your browser’s extensions page and click Reload on CrystalLyrics.
  4. Refresh YouTube or YouTube Music.

Using the same folder helps preserve the extension identity and saved preferences. Keep your own imported lyric files backed up.

If something does not work

  • Manifest missing: select the inner CrystalLyrics folder, not the ZIP or parent folder.
  • No lyric panel: refresh the watch page after installation and use the popup’s Show lyrics control.
  • No matching lyrics: use Find song, try again later, or import a lyric file.
  • Cover colors stay unchanged: no confident artwork match may be available. Your manual colors stay in use.
  • Video colors are blocked: some video sources restrict reading pixels. Use cover or manual colors.
  • Audio model fails to download: check your connection and access to Hugging Face. Basic lyric display and estimated word effects do not need this model.
  • Firefox, mobile, Shorts or live video: these are not supported in this release.

If you report a bug, include your browser version, extension version and the timing label shown. Report a Crystal Lyrics issue ↗

Remove the extension

Open your browser’s extensions page, find CrystalLyrics and select Remove. You can then delete its extracted folder. Browser-managed model caches may need to be cleared separately.
